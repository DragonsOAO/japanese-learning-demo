# 日語課程平台 Demo

日系大阪風格的線上日語課程平台展示網站，包含師資介紹、分級試看、模擬購課，以及學員與老師專區。

## 本機預覽

直接開啟 `index.html`，或使用任意靜態 HTTP 伺服器提供網站。

## GitHub Pages

在儲存庫 Settings → Pages 選擇 Deploy from a branch，分支選擇 `main`，目錄選擇 `/ (root)`。

## 展示說明

- 學員與老師皆可透過身分入口直接進入。
- 付款、會員驗證、觀看權限及課程資料皆為模擬，未連接正式服務。
- 示範變更僅保留於頁面記憶，重新整理後還原。
- 師資資料為虛構；圖片為 AI 生成情境示意；發音按鈕不播放音訊。
- YouTube 與課程影片尚待填入正式連結。

網站為純 HTML、CSS 與 JavaScript，無須安裝依賴或執行建置。
